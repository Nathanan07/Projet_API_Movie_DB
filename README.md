# 🎬 Movie DB API Project

Welcome to **Movie DB API Project**, a dynamic web application built to interact with movie databases. This project allows users to explore popular films, search for specific movies and actors, view detailed information, and browse content by genres.

---

## ✨ Features

* **Popular & Top-Rated Movies:** Discover what's trending and check out the highest-rated films of all time.
* **Search Engine:** Easily search for movies and actors using dedicated search pages.
* **Detailed Views:** Access comprehensive information about specific movies, cast members, and actor details.
* **Genre Filtering:** Browse movies categorized by different genres[cite: 3].
* **Advanced Section:** Includes an "approfondissement" module with advanced features, improved proxy handling (`get-proxy.php`), and enhanced UI components[cite: 3].
